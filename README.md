# progetti-packet-tracer
Esercitazioni scolastiche di networking: configurazioni router, switch e VLAN in Packet Tracer.

## Esercizio 1
Progettazione e configurazione di una rete con router, switch, dispositivi terminali e collegamento esterno ad internet simulato con router e server dedicati. Implementazione di indirizzi IP assegnati tramite subnetting, VLAN, ACL extended, SSH, rotte statiche e accesso a servizi come http ed https (web) e PostgreSQL.
La comunicazione inter-VLAN avviene tramite router-on-a-stick.

## Esercizio 2
Progettazione e configurazione di una rete simulata pensata per un'azienda di nome TECHNOVA SPA (immaginaria),con router, switch, dispositivi terminali e collegamento esterno ad internet simulato con router e server dedicati.
Implementazione di indirizzi IP assegnati tramite subnetting, VLAN, ACL extended, SSH, rotte statiche e accesso a servizi come http ed https (web), MySQL, DNS.
La comunicazione inter-VLAN avviene mediante router-on-a-stick.

## Esercizio 3
Esercizio semplice di comunicazione tra due reti.
Implementazione di indirizzi IP assegnati tramite subnetting, VLAN, rotte statiche.
La comunicazione inter-VLAN avviene mediante router-on-a-stick.

## Esercizio 4
Esercizio semplice di comunicazione tra tre reti.
Implementazione di indirizzi IP assegnati tramite subnetting, VLAN, rotte statiche.
La comunicazione inter-VLAN avviene mediante router-on-a-stick.
